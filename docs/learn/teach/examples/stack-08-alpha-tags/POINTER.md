# Example

Host runner retired. Part of https://github.com/aien-dev/sovereign-intelligence/issues/31.

Native Omega: alphachk.om, lib.om.

Recorded host output: output.txt. That file is a past Linux AArch64 host run. It is not a new execution, and it is not a GB10 or other hardware result.

The .om files are the lesson. The old run.sh compiled them with the pinned omc and compared stdout with output.txt. A program that launches omc would be a wrapper, so this retirement does not add one.
