Sovereign Intelligence alpha-20261026.2: the installer-plus-engine bundle for NVIDIA DGX Spark (GB10). Sovereign Intelligence, built on AienOS.

This release supersedes alpha-20261026.1. It offers one model, Qwen3.6-35B-A3B-FP8, with the exact engine build that serves it on my Spark. The 27B is to come; it is not offered here.

This is not the kernel. The AienOS kernel and its USB/VM artifacts live in aien-dev/aienux; its "AienOS Alpha 0.1" release is https://github.com/aien-dev/aienux/releases/tag/alpha-0.1 .

## Install

```sh
curl -fsSL https://aienos.com/install.sh | sh
```

`install.sh` (also attached here) checks the platform before it downloads anything: Linux, aarch64, an NVIDIA kernel driver, and a GB10 (PCI 10de:2e12) with driver 580.173.02. Anything else gets a friendly line pointing to https://www.aienos.com/alpha/ and exit 0, with nothing written. On a Spark it downloads this tag's assets by name (never "latest"), checks the Ed25519 signature of SHA256SUMS and the bundle's SHA-256 before unpacking, checks every file inside again, installs into `~/.local/share/aienos`, adds a menu entry and a desktop icon, and offers to open the wizard. No sudo; nothing outside your home folder.

- Source: aien-dev/aien-sovereign-core-mv branch ship/motor-l387, commit 59b05a71a33e4a2f1324db2f2b6407ee82b8c2c3 (the commit the binary embeds; the branch head f0230a59 changes only a merge-train script). It is a development build, not a Core release tag. The commit is in the history of Core main through later merges, but this binary is not a build of Core main or of a Core release tag.

- Rebuild: I built `cargo build --release -p aien-serve-http` (Rust 1.98.1) from 59b05a71 with that library, at the original build's paths (bind-mounted), and got the same sha256 19173f9e... byte for byte.

- `--help` lists `--max-context N`, `--max-tokens-cap N`, `--thinking`, `--batch-slots N`. This build has no `--version`; VERSION records its usage line instead.

## Memory

The 35B load needs 37,254 MiB for the model, 8 rows of 1,982.85 MiB for the conversations and 8,192 MiB kept free (Core qwen36_batch.rs at 59b05a71, with the live server's load log). The doctor notes a busy GB10 below 61,309 MiB = 62,780,416 kB free, and refuses machines with less than 64 GiB of memory. The plan needs the model's size plus 1 GB of disk: 38,493,015,668 bytes.

Wolfram queries: `Ceiling[37254 + 8*1982.85 + 8192]*1024 -> 62780416`; `64*1024*1024 -> 67108864`; `N[37493015668/10^9, 5] -> 37.493`; `37493015668 + 10^9 -> 38493015668`.
