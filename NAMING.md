# Naming

"Sovereign Intelligence" and "SI" are names I claim as my trademarks (see [NOTICE](NOTICE)).
This page says how to write them.

## The rules

1. **Always capitalized.** Sovereign Intelligence, never "sovereign intelligence" when it means this project.
2. **Spell it out on first use.** Write "Sovereign Intelligence (SI)" the first time, then "SI".
   "SI" also means the International System of Units, so a page that only says "SI" is ambiguous.
3. **Say what it is built on.** Write "Sovereign Intelligence, built on AienOS".
   AienOS keeps its own name and its own home in [aien-dev/AienOS-nv](https://github.com/aien-dev/AienOS-nv).
   SI never replaces or absorbs the AienOS name.
4. **Keep the other names as they are.** Aienux is the kernel ([aien-dev/aienux](https://github.com/aien-dev/aienux)).
   Omega, CUDA++ and Allen are parts of SI, not other names for it.

## Examples

| Write | Not |
| --- | --- |
| Sovereign Intelligence (SI) is my own AI on my own Spark. | SI is my own AI. *(first use, not spelled out)* |
| Sovereign Intelligence, built on AienOS | AienOS, now called Sovereign Intelligence |
| the SI installer | the si installer |

## Registration

The names are claimed, not registered. Filing a formal registration (for example with the USPTO) is
my step to take as the owner; nothing in this repository registers anything.
Until then the ™ claim in [NOTICE](NOTICE) is the whole of it.
